# 음성 기록 편집과 문맥 교정

회의 상세 → 음성 기록 → **전체 음성 기록**에서 `음성 기록 편집`으로 내용을 수정하고 `음성 기록 저장`을 누릅니다. 재생 시각과 업무 근거의 발언 ID를 보존하므로 편집 모드에서는 시간 구간별로 텍스트를 입력합니다. 검색으로 숨겨진 구간의 수정도 저장되며, 편집 취소는 저장하지 않은 내용을 버립니다. 다른 작업에서 같은 텍스트를 먼저 수정했으면 저장을 거부하며 최신 기록을 다시 불러와야 합니다. 처리 중인 회의는 편집할 수 없습니다.

각 발언 안의 **문구 수정 → 수정 문구 적용**으로 해당 발언 묶음만 바로 수정·저장할 수도 있습니다. 적용한 텍스트는 서버에 저장되고, 다음 분석 단계에서 사용됩니다. **문구 수정 취소**는 저장 전 편집 내용을 버립니다.

연속된 같은 화자의 발언은 하나의 묶음으로 표시합니다. 중간에 다른 화자가 말하면 다시 별도 묶음이 됩니다. 문구를 클릭하면 그 발언의 시작부터 종료까지 재생한 뒤 멈춥니다. 묶음의 화자·시각을 클릭하면 묶음 전체가 끝날 때 멈춥니다. 참석자 목록의 목소리 듣기도 해당 샘플 구간만 재생합니다. 원래 시간·ID와 발언 순서는 유지됩니다.

실제 음성의 화자 분석은 음성 특징 벡터를 추출해 기존 화자의 대표 목소리와 코사인 유사도로 비교합니다. 참석자를 지정했으면 해당 인원 수가 화자 수의 상한입니다. 초과한 음성 군집은 가장 비슷한 목소리끼리 병합하며, 상한에 도달한 뒤에는 새 화자를 늘리지 않고 가장 비슷한 기존 화자로 매칭합니다. 예를 들어 7명을 지정하면 화자는 최대 7명입니다. 지정한 인원과 정확히 같은 수를 억지로 만드는 것은 아닙니다. 기존 음성은 **음성별 화자 분석**으로 다시 매칭하며 수정한 전사문과 시각·ID는 유지됩니다. 화자 추정 안내는 화면에 표시하지 않습니다.

새 회의의 **AI 단계 진행 방식** 또는 회의 상세의 **AI 단계 진행 설정**에서 `자동으로 다음 단계 진행`과 `각 단계 결과 확인 후 진행`을 선택합니다. 확인 모드는 각 단계 결과를 저장하고 **다음 단계 확인 대기**에서 멈춥니다. 결과를 확인·수정한 뒤 **확인 후 다음 단계 진행**을 누르면 이어갑니다. 화면 새로고침이나 서버 재시작 후에도 대기 상태와 다음 단계는 유지됩니다. **대기 작업 취소**로 중단할 수 있으며, 대기 중 자동 모드로 바꾸더라도 다음 단계 진행을 한 번 눌러야 재개됩니다. 실행 중에는 진행 방식을 바꿀 수 없습니다. 회의 자료 분석 및 업무 분석에 적용하며 AI 일정 계산은 기존 자동 처리 방식을 사용합니다.

같은 단계 확인 버튼의 중복 요청은 이전 단계 번호를 검증해 차단합니다. 업무 분석 뒤 음성 기록을 바꿨으면 오래된 분석으로 티켓을 만들지 않도록 계속하기를 차단하므로 대기 작업을 취소하고 업무 분석을 다시 실행하세요. 확인 대기 중 새 분석을 중복 시작할 수는 없습니다.

음성 변환 및 전체 분석은 **음성 기록 준비 → AI 음성 기록 문맥 교정 → 회의록 작성 → 업무 분석 → 티켓구성** 순서입니다. 음성 변환만 요청하면 문맥 교정까지 수행합니다. 기존 기록은 `AI 문맥 교정`으로 별도 실행할 수 있습니다. 실제 OpenAI 또는 Codex 설정이 필요하며 Mock 모드는 원문을 변경하지 않습니다. 교정은 선택한 AI 계정/API의 사용량을 사용합니다.

AI는 모든 발언을 하나씩 읽고 앞뒤 대화에서 질문·응답·제안·확인의 기능, 구어체 말투, 조사·어말어미와 문장부호를 검토합니다. 단순한 단어 오타 검사가 아닙니다. 연결 상태를 확인하며 상대의 반응을 기다리는 맥락의 `소리가 들리는다`는 서술형 `소리가 들린다`로만 바꾸지 않고 `소리가 들리는데?`처럼 대화 말투를 살립니다. 자연스러운 반말·존댓말은 보존하고 모든 문장을 질문으로 바꾸지 않습니다. 구간 경계의 연결 어미도 앞뒤 같은 화자의 발언과 함께 검토합니다.

예를 들어 주간보고용 자막 초안 검토 맥락이 명확하면 `주간복 때 초연을`을 `주간보고 때 초안을`로 고칩니다. 해당 단어를 일괄 치환하는 규칙은 아닙니다. 이름·고유명사·날짜·수량·부정·조건·요청의 의미를 추측으로 바꾸지 않도록 지시합니다. 숫자가 변경된 교정 제안은 그 발언의 원문을 그대로 유지하며, 숫자를 바꾸지 않는 다른 발언의 교정은 적용합니다. 모호한 발언은 유지하도록 지시하지만 AI 교정은 오류가 있을 수 있으므로 원음과 대조하세요.

단어 자체가 문법에 맞더라도 앞뒤 상황과 어울리지 않는지 검토합니다. 방금 재생한 영상의 글자를 확인하는 흐름이라면 `한국 말풍선에 글자 없었지?`를 `방금 말풍선에 글자 없었지?`로 교정합니다. 실제 한국어·영어 말풍선을 비교하는 흐름이면 언어 이름을 유지합니다.

AI 응답에는 수정하지 않은 발언도 포함해 전체 구간을 순서대로 반환하게 하며, 누락·순서 변경이 있으면 전체 적용을 거부합니다. 완료 시 화면에 검토한 전체 구간 수를 표시하고, 이후 텍스트를 수정하면 이전 완료 표시는 해제됩니다. 음성을 직접 다시 듣는 단계와는 별도로 전사 텍스트의 대화 문맥을 검토하는 기능입니다.

교정 전 텍스트는 서버에 보관하지만 화면에 원문 보기 항목을 표시하지 않습니다. 시간·화자·발언 ID의 변경은 AI 응답에 허용하지 않습니다. 긴 기록은 나누어 교정하고, 실패·취소되면 교정 결과를 부분 적용하지 않습니다. 음성 전사는 성공하고 교정만 실패하면 전사 결과는 남습니다.

텍스트를 편집하거나 기존 기록을 교정해도 기존 회의록·업무 후보·기등록 Jira 내용은 자동 변경되지 않습니다. 필요한 회의록·업무를 다시 생성·검토하세요. 기존 회의는 서버 시작 시 자동 교정하지 않습니다.

테스트: 기본 Maven 테스트는 가짜 AI 응답으로 동작합니다. 실제 AI 예문 검증은 `RUN_LIVE_TRANSCRIPT_REVIEW=true`를 지정하고 `TranscriptReviewLiveTest`를 실행하며, 앱의 기존 Codex 로그인을 사용합니다. 이 테스트는 합성 예문만 전송하고 실제 회의 데이터는 사용하지 않습니다.
